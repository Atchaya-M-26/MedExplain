2. Choose Windows
3. Run installer

5. Click "Finish" - MongoDB auto-starts!

**Test installation**:

## 🚨 If Something Goes Wrong

### MongoDB not found
```
Download from: https://www.mongodb.com/try/download/community
```

### Port 5000 in use
```
Edit backend/.env and change PORT=5001
```

### npm errors
```
cd frontend (or backend)
npm install --legacy-peer-deps
```

### ECONNREFUSED error
```
Make sure mongod is running in Terminal 1
```

See **GETTING_STARTED.md** "Troubleshooting" section for more help.
